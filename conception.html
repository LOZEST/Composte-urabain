Le composteur

Un système automatisé pensé pour la ville.

GreenLoop n’est pas un simple bac de compost. Le projet imagine un composteur autonome avec plusieurs étapes de traitement, une logique d’identification et un meilleur suivi de l’usage.

Identification

L’utilisateur s’identifie grâce à un QR code relié à son compte dans l’application.

Pesée / mesure

Le dépôt de biodéchets peut être mesuré pour attribuer des points et suivre l’activité.

Cycle de compostage

Le système à plusieurs cuves permet de structurer les différentes étapes du compost.

Parcours utilisateur
  1. Créer un compte sur l’application
  2. Trouver un composteur à proximité
  3. Scanner le QR code
  4. Déposer ses déchets verts
  5. Recevoir des points
  6. Récupérer du compost
L’application

Une interface qui rend le compostage lisible.

L’application est essentielle dans le projet : elle donne un visage moderne au système, facilite l’usage et montre que le compostage peut devenir une expérience claire pour l’utilisateur.

Le code et l’architecture

Une logique technique cohérente.

Sur cette page, il faut expliquer le lien entre le composteur physique, les capteurs, l’application et la gestion des points.
